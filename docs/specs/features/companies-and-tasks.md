# Companies and Tasks

Статус: **draft → in progress (Day 1)**

## Goal

Аккаунт Upwork («компания») и изолированные **задачи** с чатом-стратегией
(ТЗ для агента), который помнит весь контекст.

## Scope

- CRUD компании (имя, привязка к Upwork-учётке)
- CRUD задачи (название, активна, company_id)
- Чат задачи: сообщения user/assistant, полная история в БД
- Выбор активной задачи в UI — фильтр для jobs/proposals

## Non-goals

- Хранение пароля Upwork в таблице Company (только .env / vault)
- Параллельная работа нескольких аккаунтов Upwork — **вне MVP** (один аккаунт,
  креды в `.env`). Схема (`Company` 1—N `Task`) остаётся многокомпанийной на будущее,
  но worker обслуживает одну активную задачу одного аккаунта.

## User-visible behavior

- Оператор создаёт компанию и задачу «Unity игры, $5k–$20k, без NFT».
- В чате задачи уточняет стратегию; LLM отвечает с учётом всей истории.
- Вакансии и отклики создаются в контексте **текущей задачи**.
- Только одна задача «активна» для worker в момент времени.

## Invariants

- Каждый `Job` имеет `task_id` (после миграции).
- System prompt задачи = накопленная стратегия + последние N сообщений чата.

## Edge cases and failure policy

- Удаление задачи с привязанными jobs → **soft-delete** (`is_active=0`), jobs сохраняются.
- Пустой чат → дефолтная стратегия из описания задачи (`description`).
- Нет активной задачи → jobs/proposals UI показывает подсказку «выберите задачу».
- Деактивация задачи снимает её с активной для worker; активной может быть ≤ 1 задачи.

## Route / state / data implications

- Таблицы: `companies`, `tasks`, `task_messages`; колонка `jobs.task_id` (nullable до миграции legacy-jobs).
- Связь: `Company` 1—N `Task` 1—N `Job`; `Task` 1—N `TaskMessage`.
- `Task.is_active` — флаг активности; `Task.strategy` — накопленное описание стратегии.

## Verification mapping

- `tests/test_companies_and_tasks.py`: создать компанию+задачу → добавить 3 сообщения
  в чат → перечитать из БД → история и порядок на месте; `Job.task_id` проставляется.
- Ручной чеклист: создать задачу → 3 сообщения в чат → перезагрузка UI → история на месте.
