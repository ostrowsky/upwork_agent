# Feature Specs — Upwork AI Agent

Каталог **продуктового контракта**. Определяет, *что* система делает для пользователя, а не *как* устроен код.

Подход: [spec-first-bootstrap](https://github.com/ostrowsky/spec-first-bootstrap).

## Структура

```text
docs/specs/
  README.md                 — этот файл
  product-map.md            — карта продукта (brownfield)
  spec-backlog.md           — очередь спек и статусы
  templates/
    feature-spec.md         — шаблон
  features/
    *.md                    — контракты по областям
```

## Как пользоваться

1. Найти спеку по фиче в `features/`.
2. Нет спеки — создать из `templates/feature-spec.md`.
3. Меняете поведение — обновляете спеку вместе с кодом.
4. Агент в чате **не заменяет** спеки: итог фиксируется в `docs/specs/`.

## Философия

- Спека = контракт, не «документация для красоты».
- Коротко, явно, на языке продукта.
- Неизвестное — в спеке в блоке «Unknowns», не в коде «наугад».

## Связь с другими файлами

- `AGENTS.md` — workflow агента
- `docs/specs/features/` — поведение
- `qa/` — когда появится, только верификация
