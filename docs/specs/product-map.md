# Product Map — Upwork AI Sales Assistant

Brownfield-снимок: код + ТЗ заказчика + текущее состояние репозитория.

## Продукт в одном предложении

Веб-система, в которой оператор заводит **компанию (аккаунт Upwork)** и **задачу со стратегией**, агент находит вакансии, отсеивает мусор, генерирует отклики по шаблону, ведёт переписку с клиентами и шлёт ежедневную отчётность.

## Акторы

| Актор | Роль |
|-------|------|
| Оператор | Настраивает компании, задачи, кейсы; одобряет отклики; отвечает вручную при необходимости |
| AI-агент (LLM) | Квалификация, тексты, вопросы, анализ проигрышей, черновики ответов |
| Upwork | Внешняя платформа (вакансии, сообщения, connects) |

## Целевые user flows (to-be)

1. **Онбординг:** компания → задача → ТЗ в чате задачи.
2. **Поиск:** worker/ручной импорт → список NEW jobs.
3. **Квалификация:** AI APPLY/SKIP по стратегии задачи.
4. **Отклик:** генерация 7-блочного письма + кейсы → черновик → **автосабмит** (списание connects без человека).
5. **Исход:** WIN/LOST → анализ + вопросы агенту.
6. **Клиент:** ответ заказчика → карточка клиента → AI draft / ручной режим.
7. **Отчёт:** конец дня → Telegram + история в UI.

## Границы MVP (10 дней, согласованный scope)

- **Автосабмит откликов и connects — включён** (полная автоматизация, без подтверждения человеком на submit).
- Первый логин Upwork — человек (один раз, далее сессия в `data/upwork_profile`).
- Кейсы — из базы (`case_studies`) **или** сгенерированы LLM под вакансию (`synthetic=1`,
  с PDF/PNG-вложением). Обновлено 2026-06-06: генерация на лету **разрешена** по запросу
  заказчика; синтетика всегда помечается, ToS-ответственность — на владельце аккаунта.
- Отклики на **EN и RU** (язык определяется по вакансии/стратегии задачи).

## Решения заказчика (зафиксировано 2026-06-04)

| Вопрос | Решение |
|--------|---------|
| Автосабмит connects | **Да**, полная автоматизация submit |
| Аккаунты Upwork | **Один** аккаунт; креды в `.env` (`UPWORK_EMAIL`/`UPWORK_PASSWORD`). Доступность: хост отвечает (Cloudflare 403 на ботов — обходится видимым Chrome) |
| Язык откликов | **EN + RU** |
| Источник кейсов | Только реальные записи из базы |
| Содержимое кейсов | Допускается **фабрикация опыта / case studies**; ответственность полностью на заказчике — владельце аккаунта |
| Стек | **Python** (Streamlit + SQLAlchemy + Playwright + OpenRouter) |

> Этическая/ToS-ответственность за синтетический опыт в откликах несёт владелец аккаунта Upwork (заказчик). Система лишь оперирует данными, которые оператор сам внёс в базу кейсов.
